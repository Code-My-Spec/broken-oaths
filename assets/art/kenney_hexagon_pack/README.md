# Kenney Hexagon Pack

Source: https://kenney.nl (Hexagon pack by Kenney Vleugels)
License: CC0 (public domain) — see License.txt. Commercial use fine,
credit appreciated but not required.

Reference art library for Broken Oaths — terrain tiles (grass, dirt,
sand, stone, mars), themed building sets (medieval, military, western,
sci-fi, modern, mill), objects, and pre-assembled spritesheets with XML
atlases. The medieval set maps naturally onto our Stone Age city loop
(castle, farm, mine, church, blacksmith, lumber camp).

Nothing here ships automatically: copy individual sprites into
`priv/static/images/` (resized/recolored as needed) when a feature
actually uses them. This directory is the source library, not the
served asset path.
