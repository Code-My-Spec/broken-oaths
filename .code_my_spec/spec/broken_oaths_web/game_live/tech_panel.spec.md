# BrokenOathsWeb.GameLive.TechPanel

The technology tree UI: lists all eleven Ancient-era techs with costs, prerequisite links, and locked/available/in-progress/completed state, lets the player pick a researchable one, shows the current research progress bar, and prompts the Bronze Working confirmation (only once it's actually researchable). Surface for story 902, expanded per playtest issue 133b4893.
