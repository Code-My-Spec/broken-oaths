# BrokenOathsWeb.GameLive.VassalsPanel

The feudal relationships panel. Lord view: the Vassals list with a per-vassal tribute-rate control, the gold log, and call-to-arms issue controls. Vassal view: the "Sworn to X" indicator with the current tribute rate, the gold log, and answer-or-refuse controls for an incoming call to arms. Stories 907 and 908.
