# BrokenOaths.Feudal.Vassalization

The subjugation pivot. On a capture that leaves the defeated player with zero free (non-occupied) cities, creates the Vassalage relationship with default forward-looking fields, records the vassal's secret Hidden Agenda pick from the Oath screen, and notifies both players. Deterministic resolution when several last-cities fall in one tick. The vassal keeps playing fully. Story 907.
