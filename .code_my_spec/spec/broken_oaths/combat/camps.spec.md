# BrokenOaths.Combat.Camps

Barbarian camp lifecycle: first-city spawn trigger (4-6 camps at 8-15 hexes biased to region boundaries plus 1-2 in-region, unexplored tiles only, pile-up allowed), the per-boundary spawn loop (1 barbarian warrior per 3 turns, capped at 2 alive per camp, stats 15/15/120), and destruction consequences (30 gold to the destroyer, spawning stops, tile reverts to normal buildable terrain, orphaned warriors persist).
