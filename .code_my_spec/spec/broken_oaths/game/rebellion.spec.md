# BrokenOaths.Game.Rebellion

Rebellion / Declare Independence engine (stories 915 and 917). Severs the Vassalage, stops tribute, declares war; resolves which occupied cities RISE back to the vassal by the lord's reputation (Honor + tribute rate) vs stay loyal (retaken only by normal Siege); spawns a TEMPORARY rebellion army sized by Oath Strain that disbands after the war. Also handles story 917: on a Lord unit's death, notifies every vassal ("seize the moment") and lets each choose to declare independence via this same path — no forced cascade, no buff. Depends on Vassalage, Vassalization, Siege, OathStrain, Tribute/Honor. Behind :feudal_enabled.
