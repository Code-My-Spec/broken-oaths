# BrokenOaths.Game.RebellionPact

Pact of Broken Oaths record (story 916). A lightweight persisted object binding fellow vassals of one lord to a shared strike turn with secret per-member commitments (hidden from the lord and from each other until reveal). At the strike turn all commitments reveal and each committed member declares independence via Rebellion (915) — purely social, no coordination bonus. Models the informer (an invitee can secretly warn the lord for a reward, identity hidden) and exposes conspiracy "heat" (aggregate strain) to the lord for pre-emptive concessions. Persisted via the WorldServer tick delta. Behind :feudal_enabled.
